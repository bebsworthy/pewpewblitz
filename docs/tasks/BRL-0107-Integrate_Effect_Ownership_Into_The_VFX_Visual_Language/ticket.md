# Description

## Outcome

Replace the current generic relationship annulus drawn above persistent combat effects with ownership and team readability integrated into each effect's own visual composition.

Self, ally, enemy, and neutral meaning must remain quickly readable, but it should be expressed through an effect-owned boundary treatment, rim, cadence, silhouette detail, or other composable layer that preserves the Fire, Cold, Poison, Restoration, and future style identities. The relationship treatment must not visually read as a second unrelated circle or overpower the effect.

This is a deferred follow-up to the BRL-0094 implementation sequence, based on native Fire-field feedback: the current bright green self-owned inset dominates the production effect and is absent from the neutral VfxLab fixture.
