# Description

Replace the central gameplay-content fingerprint tuple with a bounded, deterministic registry of stable domain contributions populated by shared content plugins. All production roles and pre-Startup routing validation must fingerprint the same live resources, so adding another gameplay catalog requires a domain registration instead of central aggregation edits while protocol shapes, headless safety, and the global compatibility gate remain intact.
