# Outcome

Players can choose a second accepted Wipeout 3v3 layout whose combat rhythm and viable builds differ materially from the current purpose-built Wipeout map.

# Scope

- Author one new sparse-grid map recipe with stable identity, three-per-team spawn capacity, safe re-entry routes, readable bounds, and no mode anchors beyond Wipeout requirements.
- Use established ground, walls, destructible cover, concealment, barrels, chests, pickups, water, and decoration profiles only where they create deliberate decisions.
- Design for at least two viable approaches, meaningful close/mid/long-range opportunities, limited dead space, and no indefinite disengagement route.
- Add it as an advertised Wipeout game type through the existing server-owned catalog and routed admission path.
- Reuse current themes or accepted visual profiles; new gameplay mechanics and a new rendering system are outside scope.
- Validate current Practice navigation and objective-neutral combat on the map.

# Acceptance criteria

- The recipe resolves, advertises, admits, restarts, recovers, and renders through production paths.
- Spawn safety, fighter clearance, projectile readability, bot navigation, destructible state, and maximum 3v3 performance pass.
- Native keyboard/controller playtests confirm that the layout produces distinct but fair range and flank decisions.
- Feedback, final recipe rationale, evidence, and durable map documentation are recorded.
