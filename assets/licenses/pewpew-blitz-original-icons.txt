PewPew Blitz original shell icon set

Files: brawler/ui/icons/*.png

These icons are original work of the PewPew Blitz project (BRL-0157). They are generated by the
checked-in script asset_src/player-shell/icons/build_icons.py (Python 3 standard library), which
also writes their editable SVG sources to asset_src/player-shell/icons/svg/. They contain no
third-party, purchased, AI-generated or hand-edited artwork. The README beside the script records
the build command, style contract and inventory.

Since BRL-0157 the shell no longer ships the Kenney Game Icons pack; its license text was retired.
