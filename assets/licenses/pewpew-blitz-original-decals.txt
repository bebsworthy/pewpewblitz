PewPew Blitz original floor decals

Files: brawler/textures/original/environment/floor-decals.ktx2

This decal atlas is original work of the PewPew Blitz project (BRL-0178). It is generated by
the checked-in script asset_src/environment/floor-decals/build_decals.py (Python 3.14+ standard
library), which defines every sprite as code. It contains no third-party, purchased,
commissioned, AI-generated, or hand-edited image data. The README beside the script records the
build command, the atlas contract, and the inventory.
