PewPew Blitz original environment kits

Files: brawler/models/original/environment/<kit>/*.glb

These models are original work of the PewPew Blitz project. They are generated by the
checked-in procedural Blender builders under asset_src/environment/<kit>/ (sharing
asset_src/environment/kit_common.py) and contain no third-party, commissioned, AI-generated,
or hand-edited model data, textures, or images.
Each kit's README (for example asset_src/environment/crossroads-facility/README.md) records
the build command, the Blender version, the kit contract, and the piece inventory.

Kits:
- crossroads-facility (map presentation theme 1), BRL-0153, built with Blender 5.2.3 LTS.
- tidal-garden (map presentation theme 2), BRL-0187, built with Blender 5.2.3 LTS.
- ashen-court (map presentation theme 3), BRL-0188, built with Blender 5.2.3 LTS.

Since BRL-0188 every shipped environment model is one of these original kit pieces; the
third-party Kenney and KayKit environment packs were retired with their license texts.
