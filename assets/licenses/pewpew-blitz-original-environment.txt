PewPew Blitz original environment kits

Files: brawler/models/original/environment/<kit>/*.glb

These models are original work of the PewPew Blitz project. They are generated by the
checked-in procedural Blender builders under asset_src/environment/<kit>/ and contain no
third-party, commissioned, AI-generated, or hand-edited model data, textures, or images.
Each kit's README (for example asset_src/environment/crossroads-facility/README.md) records
the build command, the Blender version, the kit contract, and the piece inventory.

Kits:
- crossroads-facility (map presentation theme 1), BRL-0153, built with Blender 5.2.3 LTS.
