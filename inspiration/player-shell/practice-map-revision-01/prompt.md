Show a centered compact PRACTICE map-picker modal over the softly darkened Dashboard. Preserve underlying Dashboard composition and clean branding. Modal occupies roughly 68% screen width and 66% screen height, a clean cream lightly skewed panel, navy border with orange offset backing. Inside: large left-aligned heading PRACTICE. Center two equal large horizontally adjacent clickable map tiles, each with ONLY its prominent map name. Left tile text FEATURE YARD; right tile text VERDANT CROSSFIRE. Two-line titles allowed, confidently composed with generous inner padding. Use clean typography-led tiles without icons, no fake screenshots, no decorative map patterns, no preview placeholders. Right tile is orange to express selected choice, left is cream with navy outline. Right tile also has a strong cream/navy inner focus frame and small side pointer to communicate gamepad navigation focus. NO Selected label, checkmarks, map numbering, repeated mode labels, subtitles or instructions. Along lower-right of modal one substantial orange skewed button START PRACTICE with a right chevron. No Back button, no Save, no second confirmation, no team-size selector here. Keep enough whitespace to be elegant but not empty. Make the visual feel like a coherent sibling of the approved dashboard. This is a real finished UI proposal, no annotations or device frame.
