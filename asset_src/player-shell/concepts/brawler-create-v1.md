# Create Brawler v1 — proposed

BRL-0124. Built-in image_gen with approved details screen as style reference. Artwork is illustrative.

## Exact generation prompt

Create ONE 16:9 fullscreen CREATE BRAWLER game-menu mockup for PewPew Blitz. Attached image is approved style reference only: clean cream background, deep navy thick angular outlines, teal, strong orange, bold condensed game typography, restrained offset shadows. No grime, arbitrary patterns, environmental scenery, currencies, rarity, logo or controller hints. Character/model renders are illustrative stand-ins matching reference, not new character assets.
One small BACK TO BRAWLERS top-left. Centered header CREATE BRAWLER, modest height. Main content is THREE illustrated choice panels spanning the width with equal widths, generous gutters and air: FIGHTER, WEAPON, ULTIMATE. Each entire card is clickable and has one chevron to open a fullscreen choice page, never cycle-arrow pairs or nested buttons. All three cards use cream/navy; only WEAPON card has orange focus outline and a small outside focus chevron, no orange outline elsewhere except Create CTA. Left card FIGHTER: large friendly orange robot from reference standing within card, selected name DEFAULT beneath, concise smaller descriptor 'Health • Speed • Reveal range'. Middle WEAPON card: large isolated clean orange/white/cyan futuristic Pulse pistol on soft shadow, chosen name PULSE beneath, concise descriptor 'Customizable parts'. Right ULTIMATE card: bold teal/navy Dash emblem (running person with motion streaks) visually strong but sized consistently with other art, selected name DASH beneath and concise descriptor 'Change anytime'. Make panels comfortably sized about 48% screen height, NOT giant spreadsheet rows. Three panels are fully visible and art never overlaps frame or labels.
Below the three panels, a single understated sentence 'Fighter and weapon are fixed after creation.' This communicates the real irreversible choice without warning triangle or alert panel. Then roomy bottom row: left 60% is a clean navy-outline name input with small label NAME above and example editable text SPARK inside. Right 32% is a prominent orange angled CREATE BRAWLER action with navy lettering. No separate Save or Cancel, no 'selected' text, no artificial checklist, no extra footer instructions. Clean simple teal diagonal field bottom-left and orange bottom-right sweep as in reference. All safe margins and labels fit, strong game UI hierarchy, polished and coherent. Output only the mockup.

## Behavior

Whole cards open fullscreen visual pickers; selection returns to the creation draft. Name can be edited before the single Create action. Fighter/weapon immutability is stated once because it affects the creation decision. Existing backend name handling must be checked before implementing the proposed name field; do not silently create then rename as two transactions. Current editor lacks this direct name field and visual pickers, so these are design proposals pending approval. Only authored server-advertised choices may be displayed. No runtime changes. User approval pending.
