## Shell chrome

`python3 asset_src/player-shell/build_shell_art.py` (Python 3 standard library only, BRL-4jdx)
writes each code-authored chrome piece a screen loads as an editable SVG in this directory and a
runtime PNG in `assets/brawler/ui/shell/`, rasterized from the same geometry by an anti-aliased
signed-distance renderer. The SVGs contain only decoration, never interface text; native Bevy
labels, button semantics and flow ownership remain intact.

- `panel-identity` (BRL-0114): the Dashboard identity plate, an angled ink panel on a sand offset
  lip, 2× export.
- `underline` (BRL-0114): the Dashboard title underline arrow, 2× export.
- `game-selection-background` (BRL-0116, BRL-0156): the BRL-0140 `shell-bg` gradient with two
  low-contrast tonal planes, shared by the game-select, Practice, brawler, equipment, confirmation,
  connection, loading and results screens. The Dashboard shader draws the same planes natively.
  Screens own strong image handles while mounted; no generated full-screen mockup is used at
  runtime.

BRL-4jdx retired the unreferenced Sharp exports: the five other BRL-0114 action panels and every
panel focus outline, the BRL-0116 game cards, the Practice card frames, and their
`generate-chrome.cjs`, `generate-game-selection.cjs` and `generate-practice-cards.cjs` exporters.
The rebuilt PNGs match the earlier Sharp exports up to anti-aliasing at shape edges. A guard test
in `packages/brawler-client/src/ui/icons.rs` fails when `assets/brawler/ui/shell/` holds a PNG no
screen loads.

## Practice map overviews

Run `python3 asset_src/player-shell/generate-map-overviews.py` (standard library only; it reuses
the `build_shell_art.py` rasterizer). It writes the SVG source to `map-overviews/` and the runtime
PNG, fit inside 1200×800, to `assets/brawler/ui/shell/<map key>-overview.png`. The seven original
schematic overviews encode actual authored map dimensions, placements, filled rectangles, rotated
footprints and spawn points. They are overview diagrams, not gameplay screenshots. Regenerate when
map geometry changes. `render-map-overviews.cjs` (Sharp) was retired by BRL-4jdx.
